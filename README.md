# LOGIC LAB

数字电路逻辑实验室，包含两种实验模式：

- **组合逻辑模式**：逻辑门即时传播，配合真值表完成组合电路任务。
- **时序实验模式**：时钟与寄存器实验，搭建两级流水电路，观察数据在时钟上升沿逐级移动。

## 时序实验能力

- **周期时钟（手动单步）**：每次单步让所有时钟同时产生一个上升沿，支持空格键快捷单步。
- **上升沿 D 寄存器**：同一上升沿上的全部寄存器统一读取边沿前的数据，数据每拍只前进一级，
  不会因元件摆放顺序而一拍穿过两级。
- **异步复位**：按下立即清零寄存器并中断采样窗口；释放复位不会自行产生采样边沿。
- **建立/保持时间**：采样窗口为闭区间 `[-t_su, +t_h]`，数据在窗口内（含恰好落在边界）变化即标记违例，
  受影响的采样结果变为未知 `X`。
- **逐拍输入激励**：可编排未来若干拍的激励值，并设置激励相对上升沿的施加时刻。
- **状态轨迹**：逐拍记录各节点输出、采样明细与违例标记。
- **反馈规则**：经过寄存器的反馈允许存在；纯组合反馈环会被明确标出，环上信号置为未知。
- **暂停后改接线**：检测到结构变化会重新建立实验初态并清空轨迹。
- **保存分离**：电路配置与已录制的实验轨迹分开存储、分别导出。

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查、构建与时序引擎验证：

```sh
npm run typecheck
npm run build
npm run test:timing
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。
